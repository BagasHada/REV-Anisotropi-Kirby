# Citra sumber Kirby

Berkas citra biner RAW tidak disertakan di repositori publik ini karena berasal dari bundel resmi mata kuliah dan izin redistribusi publiknya belum dipastikan.

Untuk menjalankan notebook dan program:
1. Peroleh `Kirby_2d25um_binary_256.raw` dari bundel resmi mata kuliah.
2. Simpan berkas tersebut di folder ini dengan nama persis `Kirby_2d25um_binary_256.raw`.
3. Pastikan ukuran berkas 16.777.216 byte (256³ voxel × 1 byte).
4. Jangan mengubah urutan byte, urutan C, atau nilai voxel (0 = pori, 1 = padatan).

Path ini sesuai dengan `raw_file` pada `data/metadata.json`.
