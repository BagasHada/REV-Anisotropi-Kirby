# Data

Metadata citra tersedia pada `metadata.json`, dan nilai pembanding permeabilitas domain penuh tersedia pada `referensi_permeabilitas.csv`.

Citra sumber yang digunakan adalah citra biner micro-CT Kirby berukuran 256³ voxel, `uint8`, urutan C, ukuran voxel 2,25 µm; nilai 0 = pori dan 1 = padatan. Berkas RAW tidak disertakan dalam repositori publik ini karena berasal dari bundel mata kuliah dan izin redistribusi belum dipastikan.

Untuk menjalankan program, peroleh `Kirby_2d25um_binary_256.raw` dari bundel resmi mata kuliah dan letakkan pada `data/citra/`. Petunjuk lengkap dan pemeriksaan ukuran tersedia di `data/citra/README.md`.
